API HoneyForge

Документация OpenAPI доступна целиком внутри лаборатории. Пользовательские запросы используют сеансовую cookie HttpOnly. Для изменений требуется заголовок X-HoneyForge: 1. Машинные запросы используют X-Agent-ID и токен Bearer.

# Дизайн интерфейса

Интерфейс HoneyForge — рабочий инструмент в стиле «жидкого стекла»: блоки — полупрозрачные стеклянные панели над мягким цветным фоном, один акцентный цвет для действий и опасности, цвет состояний только там, где он несёт смысл. Есть светлая и тёмная темы. Архитектура прежняя: HTML, CSS и модули JavaScript без сборки.

## Принципы

1. Данные важнее оформления. Стекло и движение не закрывают данные, не двигают соседние элементы и не повторяются при живом обновлении данных.
2. Красный — цвет главного действия и критических состояний, а не всех состояний. Успех, предупреждение и сведения имеют собственные цвета.
3. Состояние никогда не передаётся только цветом: рядом всегда есть текст.
4. Неизвестное значение не показывается нулём. У каждого блока три состояния: загрузка, ошибка, данные.
5. Все числа на экране получены от сервера.
6. Любой информационный блок можно свернуть до заголовка, чтобы оставить на экране только нужное.

## Темы

Все цвета заданы переменными в начале `frontend/style.css`; темы отличаются только значениями переменных.

| Выбор | Как задаётся |
|---|---|
| Как в системе (по умолчанию) | Тема следует настройке операционной системы и меняется вместе с ней |
| Светлая или тёмная | Атрибут `data-theme` у корневого элемента |

Переключатель в шапке меняет тему между светлой и тёмной; вариант «Как в системе» выбирается в разделе «Настройки». Выбор хранится в браузере.

| Группа | Переменные |
|---|---|
| Поверхности | `--hf-bg`, `--hf-surface`, `--hf-surface-2`, `--hf-input`, `--hf-border`, `--hf-border-soft`, `--hf-hover`, `--hf-overlay` |
| Текст | `--hf-text`, `--hf-text-2`, `--hf-text-3`, `--hf-link` |
| Акцент | `--hf-accent`, `--hf-accent-hover`, `--hf-accent-soft`, `--hf-on-accent` |
| Состояния | `--hf-success`, `--hf-warning`, `--hf-critical`, `--hf-info`, `--hf-neutral` и для каждого `-soft` (фон) и `-text` (текст) |
| Графики и карта | `--hf-chart-grid`, `--hf-map-bg`, `--hf-map-land` |
| Радиусы, отступы, движение | `--hf-radius-*` (6, 10, 14), `--hf-space-1` … `--hf-space-7`, `--hf-transition-*` (140 и 220 мс) |

Мелкий текст (`--hf-text-3`) подобран с контрастом не ниже 4,5:1 к поверхности в обеих темах; это рассчитано вручную, автоматическая проверка не выполнялась.

## Жидкое стекло

| Слой | Как устроен |
|---|---|
| Фон | Один неподвижно закреплённый слой под содержимым: три размытых цветных пятна в цветах логотипа (фиолетовый, красный, жёлто-зелёный), которые медленно плывут (46 секунд на цикл). Движется только преобразование слоя, поэтому прокрутка его не перерисовывает |
| Панель | Полупрозрачная заливка (`--hf-glass`), размытие и усиление насыщенности фона за ней (`backdrop-filter: blur(22px) saturate(170%)`), мягкая тень |
| Кромка | Градиентная рамка в один пиксель, яркая в левом верхнем и правом нижнем углах, как блик на ребре стекла |
| Блик под указателем | У карточек показателей, карточек каталога и карточки входа: световое пятно следует за указателем; положение передаётся двумя переменными, запись — не чаще одного раза за кадр |

Стеклянными сделаны блоки (`panel`), карточки (`glass`, `card`), боковая панель, шапка, меню, диалоги, уведомления и подсказки графиков. Меню, диалоги и подсказки используют более плотное стекло (`--hf-glass-strong`), чтобы текст оставался читаемым над любым содержимым. Поля ввода и строки таблиц стеклом не делаются.

Если браузер не поддерживает размытие фона, панели получают сплошную заливку. То же происходит при включённом параметре «Уменьшить визуальные эффекты»; фон при этом перестаёт двигаться.

## Движение

| Что | Когда |
|---|---|
| Блоки поднимаются на место один за другим | Только при открытии страницы. Живое обновление данных блоки не анимирует |
| Числа досчитывают до нового значения | Когда показатель изменился: карточки и плитки сетевой активности |
| Новая строка въезжает в ленту событий | Когда событие пришло по живому каналу |
| Карточка приподнимается, кнопка слегка сжимается | Наведение и нажатие |
| Индикатор соединения «дышит», состояния «выполняется» пульсируют, по красной полосе «Опасность» идёт блик | Постоянно, пока состояние действует |
| Диалог и уведомление появляются с лёгким пружинящим увеличением; свёрнутый блок разворачивается с проявлением | Открытие |
| Смена темы — плавный переход всей страницы | Переключатель в шапке и настройки (в браузерах с поддержкой переходов представления) |

Всё движение отключается системной настройкой уменьшения движения и параметром «Уменьшить визуальные эффекты и анимацию».

## Шрифты

Весь текст набран одним шрифтом: Onest, при его отсутствии Segoe UI или системный. Идентификаторы, адреса и время — Cascadia Mono или Consolas. Числа выводятся моноширинными цифрами. Файлы шрифтов в репозиторий не входят: чтобы подключить Onest, положите файлы в `frontend/fonts` (например, `Onest-Variable.woff2`) и пересоберите образ — сервер сам объявит их в `/fonts.css`. Onest распространяется по лицензии SIL OFL 1.1.

## Сворачиваемые блоки

У каждого блока (`panel`) в заголовке есть кнопка со стрелкой. Свёрнутый блок оставляет только заголовок и элементы управления в нём. Состояние запоминается в браузере для каждой пары «страница — заголовок блока». Кнопка доступна с клавиатуры и сообщает своё состояние через `aria-expanded`. После разворачивания графики перерисовываются под новый размер.

## Компоненты

| Семейство | Классы | Примечание |
|---|---|---|
| Кнопки | по умолчанию, `primary`, `ghost`, `danger`, `loading`, `icon-button`, `segmented` | Красная заливка только у главного действия страницы |
| Карточки | `metric-card`, `glass`, `panel`, `card`, `tile` | Стеклянные панели; `tile` — плитка показателя внутри панели |
| Формы | `input`, `select`, `textarea`, флажок, `form-grid`, `form-section`, `filters`, `inline-filter` | Фокус — рамка и мягкое кольцо цвета акцента; ошибка — пунктирная рамка |
| Обратная связь | `#toast`, `notice`, `error-banner`, `load-error`, `skeleton`, `empty`, `dialog` | Ошибка загрузки блока содержит кнопку повтора |
| Данные | `table`, `pagination`, `badge`, `key-values`, `bars`, `meter`, `chart`, `feed`, `health-list` | Значок состояния — точка и текст на мягком цветном фоне |

Иконки — собственный набор линейных значков в `frontend/icons.js`. Они декоративны и скрыты от программ чтения с экрана; смысл несёт подпись.

## Оболочка

Боковая панель разбита на группы «Мониторинг», «Ловушки», «Инфраструктура», «Система»; активный раздел выделен мягкой подложкой. Панель сворачивается до значков. На ширине меньше 1024 пикселей она выезжает поверх содержимого по кнопке меню. В шапке: раздел, время последнего события, состояние канала живых обновлений, переключатель темы, оповещения и меню пользователя.

## Адаптивность

| Ширина | Раскладка |
|---|---|
| от 1800 | Шесть плиток сетевых показателей в ряд |
| 1181–1799 | Полная боковая панель, две колонки блоков |
| 1024–1180 | Блоки в одну колонку, боковая панель остаётся |
| 768–1023 | Выезжающее меню, карточки по две |
| меньше 768 | Одна колонка, прокручиваемые таблицы, элементы управления высотой не менее 40 пикселей |

## Доступность

- Видимый фокус у всех интерактивных элементов; карточки показателей, кнопки сворачивания и маркеры карты доступны с клавиатуры.
- Подписи у всех полей; у кнопок-значков есть `aria-label`.
- Поддержаны системные настройки темы и уменьшения движения.

Автоматическая проверка контраста и проверка программой чтения с экрана не выполнялись.

## Настройки интерфейса

В разделе «Настройки»: тема оформления (как в системе, светлая, тёмная), «Уменьшить визуальные эффекты и анимацию», «Плотное отображение таблиц». Свёрнутые блоки и выбор темы хранятся в браузере и не влияют на права доступа и данные.

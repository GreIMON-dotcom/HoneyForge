# API

Все пути начинаются с `/api/v1`. Полная схема с параметрами доступна на работающем сервере: `/docs` и `/openapi.json` (без обращения к внешним сетям). Имена полей и значения перечислений не переводятся; сообщения об ошибках возвращаются на русском языке в поле `detail`.

## Доступ

| Кто | Как проходит проверку | Где доступно |
|---|---|---|
| Оператор | Cookie сеанса `hf_session`; для изменяющих запросов заголовок `X-HoneyForge: 1` и разрешённый `Origin` | Порт 8443 |
| Агент экземпляра | Заголовки `X-Agent-ID` и `Authorization: Bearer`; агент должен быть одобрен и привязан к экземпляру | Порт 9443, пути `/agents/` |
| Контроллер узла | Заголовки `X-Controller-ID` и `Authorization: Bearer`; узел должен быть одобрен | Порт 9443, пути `/runtime/` |

Роли операторов: администратор (все действия), оператор (жизненный цикл, настройки экземпляров, оповещения, экспорт), наблюдатель (только чтение, без записанных имён пользователей и данных клиентов).

## Экземпляры ловушек

| Метод и путь | Назначение | Роль |
|---|---|---|
| `GET /honeypots` | Все ловушки; фильтры `q`, `status`, `service_key`, `host_id`, `profile_id` | любая |
| `POST /honeypots/validate` | Проверка конфигурации без создания: порт, ёмкость, схема | администратор |
| `POST /honeypots` | Создание экземпляра; `deploy: true` сразу запрашивает развёртывание | администратор |
| `GET /honeypots/{id}`, `GET /honeypots/{id}/health` | Сведения, контейнеры, агент, команды, развёртывания | любая |
| `GET /honeypots/{id}/configuration` | Требуемая и применённая конфигурация, доступность обновления | любая |
| `GET /honeypots/{id}/events` | События экземпляра | любая |
| `GET /honeypots/{id}/logs` | Журнал операций экземпляра | любая |
| `PATCH /honeypots/{id}` | Название, описание, теги, профиль того же семейства, собственные настройки, порт, политика обновления | оператор |
| `POST /honeypots/{id}/deploy` | Развёртывание черновика или повтор после ошибки | администратор |
| `POST /honeypots/{id}/start`, `/stop`, `/restart` | Жизненный цикл | оператор |
| `POST /honeypots/{id}/apply-updates` | Применение новой версии профиля | оператор |
| `POST /honeypots/{id}/publish` | Публикация порта ловушки на узле. Тело: `{"port": 2222}`; порт должен входить в список, сообщённый контроллером узла | администратор |
| `POST /honeypots/{id}/unpublish` | Снятие публикации | администратор |
| `POST /honeypots/{id}/clone` | Независимая копия | администратор |
| `DELETE /honeypots/{id}` | Удаление; параметр `force=true` удаляет запись без ожидания контроллера | администратор |

Тело создания:

```json
{
  "name": "Лабораторный портал 01",
  "description": "Учебная ловушка",
  "tags": ["веб"],
  "profile_id": "идентификатор профиля",
  "host_id": "lab-docker",
  "overrides": {"identity": "Портал отдела"},
  "port_mode": "auto",
  "port": null,
  "update_policy": "manual",
  "deploy": true
}
```

Запросы с неизвестными полями отклоняются с кодом 422. Образ, команду, монтирования и сети запросом задать нельзя: их определяет только контроллер по типу сервиса.

Коды ответов: 409 — конфликт названия или порта, недостаток ёмкости, недоступный контроллер, несовместимая операция; 422 — ошибка проверки конфигурации; 404 — ресурс не найден.

## События, аналитика, оповещения, аудит

| Метод и путь | Назначение |
|---|---|
| `GET /analytics/network-activity` | События по интервалам времени, итоги, распределения и самые активные источники. Параметры: `range` (`15m`, `1h`, `6h`, `24h`, `7d`), `honeypot_id`, `event_type`, `protocol`, `source_ip` |
| `GET /analytics/geography` | Источники по странам и точки карты для публичных адресов. Параметры: `range` (`24h`, `7d`, `30d`, `all`), `honeypot_id` |

| `GET /analytics/summary` | Счётчики за период и за предыдущий, состояние ловушек, выводы, страны. Параметры: `range` (`1h`, `24h`, `7d`, `30d`), `honeypot_id` |
| `GET /analytics/top` | Самые частые имена пользователей, команды и адреса страниц; наблюдателю не отдаются |
| `GET /sessions`, `GET /sessions/{honeypot_id}/{session_uid}` | Последние сеансы и ход одного сеанса |
| `GET /sources/{адрес}` | Карточка адреса источника |
| `GET /export/sources` | Экспорт публичных адресов источников: `range`, `format` (`txt`, `csv`). Оператор и администратор |

Определения показателей и правила геолокации описаны в [отдельном документе](analytics.md).

Остальные разделы не изменились: `GET /events` с фильтрами и страницами, `GET /events/{id}`, `GET /events/export` (форматы `csv` и `ioc`), `GET /analytics/overview`, `/timeline`, `/protocols`, `/sources`, правила `GET/POST/PATCH/DELETE /alerts/rules`, `GET /alerts`, `POST /alerts/{id}/acknowledge` и `/resolve`, `GET /audit`, `GET /settings`, `GET /health`, `GET /ready`. Добавлен тип события `data_received` и показатели `failed` и `drafts` в обзоре.

Канал `GET /ws` (WebSocket, cookie сеанса и проверка `Origin`) передаёт сообщения `events` с идентификатором ловушки и краткими сведениями о новых событиях (без содержимого запроса), `status` при изменении состояния и `alert` при срабатывании правила.

## Канал агента

| Метод и путь | Назначение |
|---|---|
| `POST /agents/register` | Отметка о связи; возвращает признак одобрения |
| `GET /agents/{id}/configuration` | Снимок конфигурации экземпляра, поколение и требуемое состояние |
| `POST /agents/heartbeat` | Состояние приманки, применённое поколение, размер очереди |
| `GET /agents/{id}/commands` | Незавершённые команды экземпляра |
| `POST /agents/{id}/telemetry` | Пакет событий; ответ перечисляет принятые идентификаторы |

## Канал контроллера

| Метод и путь | Назначение |
|---|---|
| `GET /runtime/desired` | Экземпляры узла: присутствие, семейство эмулятора, псевдоним, порт, ограничения |
| `POST /runtime/instances/{id}/credential` | Регистрация хеша нового секрета агента; возвращает идентификатор агента |
| `POST /runtime/report` | Наблюдаемое состояние контейнеров, выполненные действия, удалённые экземпляры, измерения узла |

Требуемое состояние не содержит секретов, имён образов и команд. Контроллер подставляет образ и команду из собственного списка разрешённых.

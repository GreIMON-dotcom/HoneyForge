# Отчёт о русской локализации HoneyForge

Проверено 11 октября 2026 года в существующем репозитории, относительно исходной версии `cf3d734`. Русский язык включён по умолчанию. Переведены все девять разделов, вход, формы, подтверждения, уведомления, состояния, сообщения проверки данных, справочник API, собственный вывод эксплуатационных скриптов и документация. Приложение сохраняет архитектуру интерфейса без сборки.

## Реализация

В `frontend/locales/ru.json` находятся 460 строк с семантическими ключами. Общие функции поддерживают вложенные ключи, именованные параметры, русские формы количества, числа, даты и относительное время. Проверены значения 0, 1, 2, 5, 11, 21, 22, 25 и 101. Неизвестные ключи получают безопасную русскую замену; диагностические ключи не показываются оператору.

Статусы, роли, критичность, типы событий и операции аудита переводятся при отображении. HTTP-коды, адреса API, имена полей JSON, значения перечислений, форматы сообщений агента и WebSocket сохранены. Обработчик ошибок проверки данных переводит сообщение, сохраняя тип ошибки, расположение поля и контекст. Русские подписи добавлены в OpenAPI и автономный справочник `/docs`.

Существующие названия и телеметрия не переписываются. Новые стандартные профили получают русские названия; инициализация распознаёт также прежние названия, чтобы не создавать дубликаты. Даты отображаются в часовом поясе браузера, хранение UTC не меняется. Пользовательские значения экранируются после подстановки перевода.

Для длинных русских надписей исправлены переносы в навигации, заголовках, панелях действий и сведениях. Верхняя панель увеличивается по высоте; кнопка выхода остаётся доступной на планшете. Таблицы прокручиваются внутри своего контейнера. Формы получили однозначные русские доступные названия и сообщения обязательных полей даже при английской локали браузера.

## Оставшиеся английские строки и границы перевода

Полный [машиночитаемый отчёт](localization-audit.json) содержит путь, номер строки, исходный текст и причину каждого из 42 исключений. Это снимок окончательного аудита исходников, а не список дефектов перевода.

- HoneyForge и общепринятые технические обозначения остаются без перевода.
- Исходные названия вроде `Lab low` и `Demo low`, пользовательские описания и имена учётных записей сохраняются. Изменять их автоматически запрещает требование сохранности пользовательских данных.
- Три английских описания исходной телеметрии в `honeypots/service.py` сохранены дословно: `Laboratory client connected`, `Synthetic administration login attempt`, `Viewed synthetic service status`. Тип, критичность и метаданные этих событий имеют русские подписи; исходная запись остаётся неизменной.
- JSON, CSV/IOC, схемы API, идентификаторы, имена протоколов и переменных, SQL и команды сохраняют машинный формат. Для просмотра исходного JSON предусмотрена поясняющая русская подпись.
- Имена субъектов сертификатов и строки сопоставления ошибок сторонних библиотек остаются техническими значениями. Вывод оператору в интерфейсе переведён.
- Docker, PostgreSQL, Alembic, pytest и системные средства могут выдавать собственную английскую диагностику. Сообщения проверок для разработчика и исходные термины двуязычного глоссария также не являются элементами интерфейса оператора.

Статический аудит использует синтаксический анализ JavaScript/Python и проверку HTML, словаря и прозы. Его дополняют проверка видимого текста в браузере и визуальный осмотр. Эти проверки покрывают перечисленные сценарии; они не доказывают отсутствие любой возможной ошибки при произвольных будущих данных или изменениях.

## Не выполненные отдельно проверки

- Рабочий процесс GitHub Actions подготовлен, но на GitHub не запускался. Изменения не отправлялись в удалённый репозиторий.
- После локализации не повторялась отдельная установка из архива на совершенно чистой машине: выполнены сборка и запуск существующей Compose-лаборатории, миграции на временном чистом PostgreSQL, новые динамические контейнеры и проверка содержимого архива. Историческая проверка чистой поставки исходной версии отмечена отдельно в `status.md`.
- Safari, Firefox и реальные мобильные устройства не использовались. Адаптивность проверена в Chrome на трёх размерах окна; это не проверка всех браузеров.
- Необязательные функции P2 не добавлялись и не заявляются проверенными. Их ограничения перечислены в `status.md`.

## Поставка и повторение

Исходный архив создаётся командой `python infrastructure/scripts/package.py`: `artifacts/honeyforge-source.zip`. Внутри находятся исходники, документация и `SOURCE-MANIFEST.json` с SHA-256. Локальные секреты, сертификаты, базы, рабочие очереди, сторонние среды выполнения и снимки браузера не входят в архив. Полный отчёт исключений включён в `docs/localization-audit.json`.

Команды повторения приведены в [README](../README.md) и [описании локализации](localization.md). Для текущей лаборатории интерфейс доступен по `https://localhost:8443`; дополнительные узлы приёмки удалены, базовая лаборатория сохранена.
